# Bopl Clone

Welcome to **Bopl Clone**, a fast-paced, physics-based 2D multiplayer brawler built in Unity. This project was developed as a team during a GameJam, serving as our introduction to the world of game development, physics engines, and multiplayer mechanics.

Inspired by the chaotic fun of *Bopl Battle*, this game challenges players to outsmart and outmaneuver each other using wacky abilities and environmental physics.

---

## Features
* **Physics-Based Chaos:** Use the environment and squishy player physics to your advantage.
* **Local Multiplayer:** Battle it out with your friends on the same screen.
* **Dynamic Arenas:** Levels designed to change the tide of battle instantly.

---

## Tech Stack & Learning Objectives
This repository marks our very first steps into game development. Our main goals during the GameJam were to learn:
* **Engine:** Unity (2D Core)
* **Language:** C#
* **Key Concepts:** Rigidbody2D physics, player input handling, collision detection, and level design under tight constraints.
